Panoramica

DB Explorer consente di connettersi a diversi database relazionali e ottenere una rappresentazione completa della loro struttura attraverso report automatici, metriche aggregate e diagrammi Entity Relationship (ER).

L'applicazione integra un assistente AI basato su Google Gemini che permette di interrogare il database in linguaggio naturale e una console SQL dedicata per eseguire query in modalità diretta senza coinvolgere servizi esterni.

Modalità standalone: tutte le funzionalità di analisi dello schema, reportistica, diagrammi ER e console SQL sono disponibili anche senza configurare una Google Gemini API Key. In assenza della chiave API, l'assistente AI fornirà un messaggio di errore chiaro.

Funzionalità Principali

Multi Database

Compatibile con SQLite, PostgreSQL, MySQL/MariaDB e SQL Server.

Diagrammi ER Automatici

Generazione dinamica delle relazioni tra tabelle tramite Mermaid.js.

AI Assistant

Analisi dello schema e supporto alle query tramite le API di Google Gemini.

Privacy by Design

Richiesta esplicita di consenso prima di consentire a Gemini l'accesso ai dati reali.

SQL Console

Esecuzione diretta di query SELECT senza utilizzo dell'assistente AI.

Protezione Read-Only

Blocco automatico di INSERT, UPDATE, DELETE, DROP, ALTER e altri comandi di modifica.

Assistente AI

L'assistente basato su Google Gemini consente di esplorare e comprendere la struttura del database utilizzando il linguaggio naturale, senza richiedere competenze SQL specifiche.

  • Analisi delle relazioni tra tabelle
  • Identificazione di chiavi primarie e foreign key
  • Spiegazione della struttura del database
  • Suggerimenti e generazione di query SQL

Le funzionalità sopra elencate operano esclusivamente sulle informazioni strutturali del database (schema, tabelle, colonne, vincoli e relazioni) e non richiedono alcun accesso ai dati contenuti nelle tabelle.

L'eventuale interrogazione dei dati reali tramite l'assistente AI è invece subordinata a un consenso esplicito dell'utente. Solo dopo l'autorizzazione Gemini avrà accesso ai dati e potrà rispondere alle richieste che coinvolgono il contenuto del database.

Privacy by Design: per impostazione predefinita nessun dato applicativo viene condiviso con Google. L'accesso ai dati è una funzionalità opzionale che richiede un'esplicita autorizzazione dell'utente.

Se ad esempio provassimo a lanciare una 'Select' con o senza consenso, otterremmo due risultati completamente diversi:

  • Nel primo caso, l'assistente AI restituirebbe il dato presente nel DB;
  • Senza consenso, invece, analizzerebbe la struttura e fornirebbe un feedback generico basandosi sulle sole informazioni che ha
Nota: Il servizio AI utilizza le API pubbliche di Google Gemini. In caso di elevato traffico potrebbero verificarsi rallentamenti o indisponibilità temporanee.
Inoltre Google applica limiti di utilizzo giornalieri alle API Key del piano gratuito.

Console SQL Integrata

La console SQL permette di eseguire query (di sola lettura) direttamente sul backend, senza passare attraverso l'AI.

  • Maggiore velocità di esecuzione
  • Nessuna esposizione dei dati a servizi terzi
  • Output immediato dei risultati

Sicurezza

L'applicazione è progettata per operare esclusivamente in modalità read-only.

  • Blocco di INSERT
  • Blocco di UPDATE
  • Blocco di DELETE
  • Blocco di DROP
  • Blocco di ALTER
  • Validazione lato backend
  • Controllo centralizzato delle query eseguibili

Interpretazione dei Diagrammi ER

I diagrammi ER utilizzano la notazione Crow's Foot per descrivere le cardinalità delle relazioni tra entità.

  • || → Esattamente uno
  • |o → Da zero a uno
  • }| → Da uno a molti
  • o{ → Da zero a molti
Nota: Le relazioni molti-a-molti vengono rappresentate tramite tabelle ponte.
Nel database demo, ad esempio, la relazione tra Orders e Products viene gestita attraverso la tabella Order_Items.

⚙️ Installazione e Avvio

1. Clonazione Repository

git clone https://github.com/morix92/DBexplorer

2. Installazione Dipendenze

npm install

3. Configurazione API Key Gemini

Modificare il file ".env" , inserendo all'interno la propria API Key Google.

È possibile generare una chiave gratuita da: Google AI Studio

4. Avvio del Server

node server.js

5. Apertura Applicazione

Aprire il browser all'indirizzo: http://localhost:3000
